# Knight Auto CRM Demo

Standalone browser demo for Knight Auto semiconductor sales management.

## Included

- Sales funnel dashboard
- Lead management with AI-assisted form filling
- Value-based pricing analysis
- Value quotation strategies and quote history
- Competitive value-price matrix

The demo stores lead and quotation history locally in the browser. It does not contain credentials, personal profile information, or external service keys.

## Run locally

Open `index.html` in a browser.
